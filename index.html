YouTube Data API v3 (ücretsiz)
1
Google Cloud Console'a git
console.cloud.google.com — normal Google hesabınla giriş yap, kredi kartı gerekmiyor.
2
Yeni proje oluştur
Üstteki proje seçiciden "New Project", istediğin bir isim ver.
3
API'yi etkinleştir
"APIs & Services → Library"da "YouTube Data API v3" ara, aç, "Enable" de.
4
Anahtar oluştur
"APIs & Services → Credentials → Create Credentials → API key". Anahtar anında oluşur.
5
Kopyala, buraya yapıştır
Yukarıdaki "API anahtarları" bölümündeki ilk kutuya yapıştırıp kaydet.
Last.fm API (ücretsiz)
1
Başvuru sayfasına git
last.fm/api/account/create — Last.fm hesabın yoksa önce ücretsiz oluştur.
2
Kısa bir form doldur
E-posta ve uygulama adı yeterli, açıklama kutusuna bir iki kelime yaz.
3
Anahtar anında çıkar
Gösterilen "API key"i kopyala, yukarıdaki ikinci kutuya yapıştır ve kaydet.
